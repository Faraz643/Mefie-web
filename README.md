# Mefie Web

A clean, editorial-style landing page for Mefie — a product built around making plans with the people and experiences that matter.

## Stack
- Semantic HTML
- Modern CSS
- Lightweight vanilla JavaScript
- Google Fonts (DM Sans + Manrope)
- Unsplash imagery for the visual prototype

## Run locally
Open `index.html` in a browser, or serve the directory with any static web server.

## Direction
The visual system is intentionally calm and premium: warm paper tones, deep ink, generous typography, soft cards, and restrained motion. The copy positions Mefie as a thoughtful alternative to noisy planning and discovery experiences.
